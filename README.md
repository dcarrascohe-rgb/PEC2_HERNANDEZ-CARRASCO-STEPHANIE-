# PEC 2 — Entrega de visualizaciones (UOC)

## Visualizaciones
- `01_coropletas.html`: mapa coroplético, esperanza de vida en países americanos de Gapminder 2007.
- `02_dendrograma.html`: dendrograma de 30 observaciones Iris; 4 variables, z-score, distancia euclidiana, enlace Ward.
- `03_arbol_hiperbolico.html`: Mundo → continente → país, datos Gapminder 2007; disco de Poincaré y reenfoque.

## Publicar
1. Crear repositorio público en GitHub.
2. Subir **todos los archivos de esta carpeta** a la raíz (index.html incluido), no el ZIP.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Esperar a que aparezca Visit site; comprobar cada enlace en ventana privada.
5. Añadir URL públicas al guion y grabar el vídeo con voz propia.

## Fuentes y transparencia
- Gapminder: https://www.gapminder.org/data/ (distribución histórica 2007 mediante Plotly Express).
- Iris: https://archive.ics.uci.edu/dataset/53/iris (distribución en scikit-learn).
- Mapa: muestra países de América presentes en Gapminder, no todos los territorios americanos.
- Dendrograma: submuestra de 30 observaciones, no inferir clases biológicas concluyentes del agrupamiento.
- Árbol: clasificación geográfica construida a partir de países Gapminder; no es árbol de clustering ni censo completo. Requiere Internet para D3 vía CDN.
